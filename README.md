## Data Science & AI Projects Portfolio
---
This repository contains a collection of projects focused on Machine Learning, Data Science, and Natural Language Processing.

### Data Science Projects
---
1. **Iris Flower Classification**<br>

**Objective**: To classify Iris flowers into three species (Setosa, Versicolor, and Virginica) based on measurements of sepals and petals.

**Tech Stack**: Python, Scikit-learn, Pandas, Matplotlib.

**Key Insight**: Implemented a K Nearest Neighbors (KNN) model to achieve high accuracy in multi-class classification.

2. **Car Price Prediction** <br>

**Objective**: To estimate the selling price of used cars based on features like mileage, fuel type, transmission, and age.

**Tech Stack**: Regression Analysis, Random Forest Regressor, Seaborn.

**Key Insight**: Identified that the *"Car Age"* and *"Present Price"* are the strongest predictors of resale value.

3. **Unemployment Analysis in India** <br>

**Objective**: To analyze the impact of the COVID-19 pandemic on the Indian labor market across different states.

**Tech Stack**: Python, Data Visualization.

**Key Insight**: Created barplots, scatter plots, and box plots to visualize the sharp spike in unemployment rates during the 2020 lockdown periods.

4. **Sales Prediction** <br>

**Objective**: To predict future product sales based on advertising spend across TV, Radio, and Newspaper channels.

**Tech Stack**: Linear Regression, Feature Engineering, NumPy.

**Key Insight**: Optimized the marketing budget by proving that TV advertising has the highest ROI compared to other media.

 ### Artificial Intelligence Projects
 ---
5. **Mental health Chatbot** <br>

**Objective**: An automated assistant designed to answer common queries on mental health using Natural Language Processing.

**Tech Stack**: NLTK, TensorFlow.

**Key Insight**: Built an intent-based classification system that allows the bot to understand user context and provide relevant responses.

6. **Language Translator** <br>

**Objective**: A real-time translator capable of converting text between multiple global languages.

**Tech Stack**: Googletrans API / Seq2Seq Models, tkinter (GUI).

**Key Insight**: Implemented a clean user interface that supports auto-detection of the source language.
